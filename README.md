# Список книг в домашней библиотеке

Веб-приложение для управления домашней библиотекой.<br/>
Backend — ASP.NET Core + Razor Pages + Dapper + SQL Server.<br/>
Frontend — HTML + CSS + JavaScript.

---

## Возможности

- [x] Просмотр списка книг
- [x] Просмотр книги
- [x] Создание книги
- [x] Редактирование книги
- [x] Удаление книги
